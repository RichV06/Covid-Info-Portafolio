# COVID-19 Data Exploration (SQL)

Exploratory analysis of global COVID-19 deaths and vaccinations in SQL Server.

## Questions answered (`Covid Info SQL.sql`)
- Case fatality rate by country over time
- Share of each country's population infected
- Countries with the highest infection rate and death count relative to population
- Death counts by continent and global totals
- Rolling vaccination counts versus population

## SQL skills
Joins, CTEs, temp tables, window functions, aggregate functions, views, data type conversion.

## Visualization
The results feed a [Tableau dashboard](https://public.tableau.com/app/profile/ricardo.chacon5015/viz/CovidProject_16486094508660/Dashboard1).
